# IHC - Guías Académicas Física

Proyecto final de la materia **Interacción Humano-Computadora (IHC)**.

## Tema

Diseño y evaluación de una interfaz administrativa para el control de distribución presencial de guías académicas en la Carrera de Física.

## Contexto

Las guías académicas de la Carrera de Física se distribuyen de forma presencial mediante el Centro de Estudiantes de Física.

Actualmente, el control de inventario, ventas, pagos, movimientos de dinero y reportes se realiza de forma manual o parcialmente desorganizada, lo que puede generar errores, pérdida de información y dificultad para realizar rendiciones de cuentas.

## Alcance

Este proyecto no propone una tienda virtual ni un sistema de ventas en línea.

La venta de guías seguirá siendo presencial.  
El sistema propuesto será un prototipo interactivo orientado al apoyo administrativo.

## Usuarios principales

- Encargados del Centro de Estudiantes de Física.
- Departamento de Física.
- Estudiantes compradores, como usuarios indirectos.

## Funcionalidades consideradas

- Registro de guías académicas.
- Control de inventario.
- Registro de ventas presenciales.
- Registro de pagos en efectivo o QR.
- Registro de gastos de impresión.
- Generación de reportes básicos.

## Enfoque IHC

El proyecto se centrará en:

- Usabilidad.
- Arquitectura de información.
- Diseño centrado en el usuario.
- Reducción de carga cognitiva.
- Prototipado.
- Evaluación de usabilidad con usuarios reales.

## Entregables

- Semana 1: Definición del problema y contexto.
- Semana 2: Investigación de usuarios.
- Semana 3: Arquitectura de información y diseño de interfaz.
- Semana 4: Prototipo funcional y evaluación.
- Semana 5: Iteración, informe final y presentación.
